# Size Property

Sets the size of a component. Supports predefined scale values and custom CSS sizes.

```jsx featured
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Badge size="md" variant="solid">
    Medium
  </Badge>
</Flex>
```

<ViewSourceLink href="https://github.com/LocusInc/locus-ui/tree/main/packages/locus-ui/src/props/size.prop.ts" />

## Examples

### Size Scale

The `size` prop accepts values `xs`, `sm`, `md`, `lg`, and `xl`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Flex gap="2" align="center">
    {["xs", "sm", "md", "lg", "xl"].map((size) => (
      <Badge key={size} size={size} variant="solid">
        {size.toUpperCase()}
      </Badge>
    ))}
  </Flex>
</Flex>
```

### Custom Size

The `size` prop also accepts custom CSS values.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Flex gap="2" align="center">
    <Badge size="2.5rem" variant="solid">
      Custom Size
    </Badge>
  </Flex>
</Flex>
```
