# Dropdown Component

A portal-backed dropdown for action menus, separators, nested dropdowns, and custom overlay content.

```jsx featured
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Dropdown.Root variant="outlined">
    <Dropdown.Trigger asChild>
      <Button variant="outlined">Actions</Button>
    </Dropdown.Trigger>

    <Dropdown.Content>
      <Dropdown.Item>Edit</Dropdown.Item>
      <Dropdown.Item>Duplicate</Dropdown.Item>
      <Dropdown.Separator />
      <Dropdown.Item destructive>Delete</Dropdown.Item>
    </Dropdown.Content>
  </Dropdown.Root>
</Flex>
```

## Anatomy

Import the component and its parts:

```jsx code
import { Button, Dropdown } from "@locus-ui/components";

<Dropdown.Root>
  <Dropdown.Trigger />
  <Dropdown.Content>
    <Dropdown.Item />
    <Dropdown.Separator />
  </Dropdown.Content>
</Dropdown.Root>;
```

## Examples

### Variants

Dropdown content supports `solid`, `outlined`, and `muted` variants.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  {["solid", "outlined", "muted"].map((variant) => (
    <Dropdown.Root key={variant} variant={variant}>
      <Dropdown.Trigger asChild>
        <Button variant={variant}>
          {variant.charAt(0).toUpperCase() + variant.slice(1)}
        </Button>
      </Dropdown.Trigger>

      <Dropdown.Content>
        <Dropdown.Item>Edit</Dropdown.Item>
        <Dropdown.Item>Duplicate</Dropdown.Item>
        <Dropdown.Separator />
        <Dropdown.Item destructive>Delete</Dropdown.Item>
      </Dropdown.Content>
    </Dropdown.Root>
  ))}
</Flex>
```

### Nested Dropdowns

Render a child `Dropdown.Root` inside another dropdown to create a submenu. Selecting a leaf item closes the full dropdown chain.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Dropdown.Root variant="outlined">
    <Dropdown.Trigger asChild>
      <Button variant="outlined">Share</Button>
    </Dropdown.Trigger>

    <Dropdown.Content>
      <Dropdown.Item>Email link</Dropdown.Item>

      <Dropdown.Root>
        <Dropdown.Trigger asChild>
          <Dropdown.Item trailingIcon={<ChevronRight />}>Copy</Dropdown.Item>
        </Dropdown.Trigger>

        <Dropdown.Content>
          <Dropdown.Item>Copy URL</Dropdown.Item>

          <Dropdown.Root>
            <Dropdown.Trigger asChild>
              <Dropdown.Item trailingIcon={<ChevronRight />}>
                Advanced
              </Dropdown.Item>
            </Dropdown.Trigger>

            <Dropdown.Content>
              <Dropdown.Item>Copy debug URL</Dropdown.Item>
            </Dropdown.Content>
          </Dropdown.Root>
        </Dropdown.Content>
      </Dropdown.Root>
    </Dropdown.Content>
  </Dropdown.Root>
</Flex>
```

### Custom Content

Dropdown content defaults to menu behavior. Use `mode="custom"` for arbitrary content.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Dropdown.Root variant="outlined">
    <Dropdown.Trigger asChild>
      <Button variant="outlined">Filters</Button>
    </Dropdown.Trigger>

    <Dropdown.Content mode="custom">
      <Box p="3" className="flex min-w-52 flex-col gap-2">
        <Text>Filter panel content</Text>
        <Button size="1">Apply</Button>
      </Box>
    </Dropdown.Content>
  </Dropdown.Root>
</Flex>
```
