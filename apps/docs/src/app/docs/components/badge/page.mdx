# Badge Component

A versatile Badge component for labeling and categorizing content.

```jsx featured
<Badge variant="solid">Top Subscriber</Badge>
```

```css preview
.badge[data-variant] {
  --badge-color: var(--color, var(--primary));

  display: flex;
  align-items: center;
  height: fit-content;
  cursor: pointer;
  border-radius: var(--lcs-radius, 1);

  padding: calc(1px * var(--lcs-spacing, 1)) calc(6px * var(--lcs-spacing, 1));
  gap: calc(5px * var(--lcs-spacing, 1));
  font-size: small;

  &[data-variant="solid"] {
    border: 1px solid rgba(var(--badge-color), 0.8);
    background-color: rgba(var(--badge-color), 0.7);
    color: white;
  }
}
```

## Anatomy

Import the component and its parts:

```jsx code
import { Badge } from "@locus-ui/components";

<Badge />;
```

## Examples

### Variants

Badge components come with four built in variants, `solid`, `outlined`, `muted`, and `clear`.

```jsx
<Flex gap="4" wrap="wrap">
  <Badge variant="solid">Solid Badge</Badge>
  <Badge variant="outlined">Outlined Badge</Badge>
  <Badge variant="muted">Muted Badge</Badge>
  <Badge variant="clear">Clear Badge</Badge>
</Flex>
```

### Colors

The badge component uses the `color` prop to allow for predefined and custom colors.

```jsx
<Flex gap="4" wrap="wrap">
  <Badge color="primary" variant="muted">
    Primary Badge
  </Badge>
  <Badge color="secondary" variant="muted">
    Secondary Badge
  </Badge>
  <Badge color="tertiary" variant="muted">
    Tertiary Badge
  </Badge>
  <Badge color="success" variant="muted">
    Success Badge
  </Badge>
  <Badge color="danger" variant="muted">
    Danger Badge
  </Badge>
  <Badge color="warning" variant="muted">
    Warning Badge
  </Badge>
  <Badge color="info" variant="muted">
    Info Badge
  </Badge>
</Flex>
```

### Sizes

To manage the size of the badge component you can provide a default or custom size through the `size` prop.

```jsx
<Flex gap="4" wrap="wrap" align="center">
  <Badge size="xs" variant="muted">
    XS Badge
  </Badge>
  <Badge size="sm" variant="muted">
    SM Badge
  </Badge>
  <Badge size="md" variant="muted">
    MD Badge
  </Badge>
  <Badge size="lg" variant="muted">
    LG Badge
  </Badge>
  <Badge size="xl" variant="muted">
    XL Badge
  </Badge>
</Flex>
```

### Color Inheritance

Works with any svg with `fill="currentColor"`.

```jsx
<Flex gap="4" wrap="wrap">
  <Badge variant="solid" color="success">
    Verified <CheckMark />
  </Badge>
  <Badge variant="outlined" color="success">
    Verified <CheckMark />
  </Badge>
  <Badge variant="muted" color="success">
    Verified <CheckMark />
  </Badge>
  <Badge variant="clear" color="success">
    Verified <CheckMark />
  </Badge>
</Flex>
```
