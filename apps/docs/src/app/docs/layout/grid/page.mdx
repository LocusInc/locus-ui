# Grid Component

A layout component that uses CSS Grid for two-dimensional layouts with configurable columns, rows, gap, flow, justification, and alignment.

```jsx featured
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="3" gap="4" align="center">
    <Box px="2" py="1" className="border">
      Item 1
    </Box>
    <Box px="2" py="1" className="border">
      Item 2
    </Box>
    <Box px="2" py="1" className="border">
      Item 3
    </Box>
  </Grid>
</Flex>
```

```jsx code
import { Grid } from "@locus-ui/components";

```

## Examples

### Gaps

The `gap` prop controls the spacing between grid items using predefined scale values `0` through `8`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="4" gap="4">
    {["0", "1", "2", "3", "4", "5", "6", "7", "8"].map((gap) => (
      <Box key={gap} px="2" py="1">
        <Text>{gap}</Text>
        <Grid columns="2" gap={gap}>
          <Box px="2" py="1" className="border">
            Item 1
          </Box>
          <Box px="2" py="1" className="border">
            Item 2
          </Box>
        </Grid>
      </Box>
    ))}
  </Grid>
</Flex>
```

### Columns

The `columns` prop sets the number of grid columns: `1` through `12`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="1" gap="4">
    {["1", "2", "3", "4", "5", "6"].map((col) => (
      <Box key={col} px="2" py="1">
        <Text>{col}</Text>
        <Grid columns={col} gap="2">
          {Array.from({ length: Number(col) }).map((_, i) => (
            <Box key={i} px="2" py="1" className="border">
              Item {i + 1}
            </Box>
          ))}
        </Grid>
      </Box>
    ))}
  </Grid>
</Flex>
```

### Rows

The `rows` prop sets the number of grid rows: `1` through `6`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="3" gap="4">
    {["1", "2", "3", "4", "5", "6"].map((row) => (
      <Box key={row} px="2" py="1">
        <Text>{row}</Text>
        <Grid rows={row} flow="column" gap="2">
          {Array.from({ length: Number(row) }).map((_, i) => (
            <Box key={i} px="2" py="1" className="border">
              Item {i + 1}
            </Box>
          ))}
        </Grid>
      </Box>
    ))}
  </Grid>
</Flex>
```

### Flow

The `flow` prop controls the auto-placement direction: `row`, `column`, `dense`, `row-dense`, or `column-dense`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="2" gap="4">
    {["row", "column", "dense", "row-dense", "column-dense"].map((flow) => (
      <Box key={flow} px="2" py="1">
        <Text>{flow}</Text>
        <Grid columns="3" rows="2" flow={flow} gap="2">
          <Box px="2" py="1" className="border col-span-2">
            Item 1
          </Box>
          <Box px="2" py="1" className="border col-span-2">
            Item 2
          </Box>
          <Box px="2" py="1" className="border">
            Item 3
          </Box>
          <Box px="2" py="1" className="border">
            Item 4
          </Box>
          <Box px="2" py="1" className="border">
            Item 5
          </Box>
        </Grid>
      </Box>
    ))}
  </Grid>
</Flex>
```

### Justify

The `justify` prop controls the inline-axis alignment: `start`, `end`, `center`, `between`, `around`, or `evenly`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="1" gap="4" className="sm:w-1/2 w-full">
    {["start", "end", "center", "between", "around", "evenly"].map(
      (justify) => (
        <Box key={justify} px="2" py="1" className="w-full">
          <Text>{justify}</Text>
          <Grid
            justify={justify}
            gap="2"
            style={{ gridTemplateColumns: "auto auto" }}
          >
            <Box px="2" py="1" className="border">
              Item 1
            </Box>
            <Box px="2" py="1" className="border">
              Item 2
            </Box>
          </Grid>
        </Box>
      ),
    )}
  </Grid>
</Flex>
```

### Align

The `align` prop controls the block-axis alignment: `start`, `end`, `center`, `stretch`, or `baseline`.

```jsx
<Flex gap="4" wrap="wrap" align="center" justify="center" className="w-full">
  <Grid columns="2" gap="4">
    {["start", "end", "center", "stretch", "baseline"].map((align) => (
      <Box key={align} px="2" py="1">
        <Text>{align}</Text>
        <Grid columns="2" align={align} gap="2" style={{ height: "100px" }}>
          <Box px="2" py="1" className="border">
            Item 1
          </Box>
          <Box px="2" py="1" className="border">
            Item 2
          </Box>
        </Grid>
      </Box>
    ))}
  </Grid>
</Flex>
```
